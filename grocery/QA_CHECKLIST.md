## Manual test cases
1. Open `grocery/index.html` on desktop and mobile viewport; verify responsive layout.
2. Submit the demo registration form; it must display a demo message and must not transmit or persist entered values.
3. Verify weekly EMI selector remains disabled until bank integration and bank approval exist.
4. Verify checkout remains disabled until Cashfree sandbox integration and merchant approval are complete.
5. Verify lucky draw is visibly disabled; no entry code is generated.
6. Apply migration to a throwaway Supabase project; verify all tables have RLS enabled.
7. As Customer A, attempt to select Customer B's application/order/payment; expect zero rows.
8. Attempt client-side insert/update to KYC, bank plan, mandate, payment, ledger, webhook and draw tables; expect denial.
9. Run catalogue seed after migration; verify exactly 416 distinct inactive SKU variants are created.
10. Verify webhook handler (when implemented) rejects invalid signatures and treats duplicate provider event IDs idempotently.
11. Verify order is released only after a verified successful payment event.
12. Verify no raw PAN, card number, CVV, PIN, bank FD account number or raw credit report is stored in app tables/logs.
