# Official Free CIBIL link — FRIEND RIDE

The Smart Grocery EMI application can offer an external link to the official TransUnion CIBIL free-score/report page:
https://www.cibil.com/freecibilscore

CIBIL provides one free score and report per calendar year. Customers complete sign-up/login and identity verification on CIBIL's site. FRIEND RIDE must not request, store, or proxy CIBIL passwords, OTPs, or identity-verification credentials, and must not scrape the report or score.

This is a user-launched external link, not a direct bureau API or automatic credit check. If an EMI eligibility workflow later requires a lender-authorized credit enquiry, implement it separately with explicit consent and a compliant authorized integration.
